# For players

Use this when you want to play the pack or join its server, and you do not need to touch the repository.

## Install

- **Modrinth App**: open the pack's Modrinth page and click Install.
- **Prism Launcher**: Add instance, Import from Modrinth (search the pack), or Import and pick a downloaded `.mrpack`.
- If the pack is not approved on Modrinth yet, download the `.mrpack` from the GitHub Releases page and import that file in Prism or the Modrinth App.

Give the game at least 4 GB of RAM (6 GB for bigger packs). Java 21 is bundled by both launchers.

## Join the server

1. Use **exactly the same pack version** as the server. Update the instance when a new version is announced.
2. Add the server address the host gave you (a playit.gg address) in Multiplayer.
3. Join. If it says mods are missing or mismatched, see [server-rejects-connection](guides/server-rejects-connection.md).

## Optional client mods

Purely visual or UI mods that run only on your side are safe to add yourself in the launcher: minimaps, shader support, cosmetic or tooltip mods. Mods that add blocks, items, mobs or recipes must also be on the server, so do not add those. If unsure, ask the host. Remove the extra mods before reporting a bug.

## If the game crashes

The Crash Assistant window opens after a crash. Click **Upload all**, then the help button, and paste the copied message where the pack asks for support.

## Verify it worked

You reach the main menu with the pack's version shown, and the server list shows the server as online with a matching version.
